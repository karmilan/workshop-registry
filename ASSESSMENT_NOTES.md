Technical Decisions and Implementation Notes

1. Technology Stack

I used React for the frontend because it supports reusable components and makes it easier to manage form inputs, validation, and API-driven UI updates. For the backend, I used Node.js and Express to build REST APIs with straightforward request handling and validation. Neon PostgreSQL was selected as the database because it provides a managed PostgreSQL environment suitable for this project.

2. Scope and Limitations

Given the limited time available for the assessment, I prioritised implementing the core requirements, connecting the frontend to the backend, and handling the main validation and error scenarios. Testing was limited, and I could not fully verify every edge case or thoroughly polish the frontend UI.
